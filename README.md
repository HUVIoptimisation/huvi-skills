# HUVI Skills

Public skills by **HUVI Optimisation** — AI agents for service businesses (construction, trades, PME).

HUVI Optimisation helps residential-service and construction businesses reclaim their time through
architecture, process design and automation. These skills are the pieces we share openly: each one
encapsulates a repeatable, well-tested workflow an AI agent can run for your business.

## Skills

| Skill | What it does |
|---|---|
| [huvi-business-architecture-optimizer](skills/huvi-business-architecture-optimizer/) | Audits a business's processes, finds shallow ones, proposes deepening redesigns as a visual HTML report, then grills through the top candidates with the owner. |

## Install

Copy the skill folder into your agent's skills directory, e.g. for Hermes:

```bash
cp -r skills/huvi-business-architecture-optimizer ~/.hermes/skills/
```

Then ask your agent to run it — for example:

> My renovation business is losing leads between texts and calls, and I spend my evenings
> doing quotes. Audit my processes and tell me what to redesign.

## Philosophy

- **You never automate chaos.** Tools and automation come last, only after a process is
  deep and documented.
- **Deep processes win.** A good process hides lots of behaviour behind a small interface
  (one normed input → structured output). Shallow processes just move the complexity around.
- **The deletion test.** If removing a process would just move the complexity elsewhere,
  it's shallow — redesign or remove it.
